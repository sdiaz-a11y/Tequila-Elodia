## Secretos

Las claves de Supabase viven solo en `.env` local (ignorado por git) y, para despliegue, en las variables de entorno de Vercel/proveedor. `SUPABASE_SECRET_KEY` nunca va al frontend ni a variables `NEXT_PUBLIC_*`.
